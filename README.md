# kink-jars
شیشه های کینک و فتیش به فارسی - اینجا میتونی علایق کینکی خودت با دیگران به اشتراک بذاری

شیشه‌های کینک
یک پرسش ‌نامهٔ تک‌ صفحه‌ای برای کینک های شما: یک رنگ انتخاب کن، هر شیشه را از ۱ تا ۵ امتیاز بده، و در پایان یک فایل PNG ذخیره کن. همه‌چیز داخل مرورگر اجرا  می‌شود. هیچ داده‌ای آپلود نمی‌شود، و پاسخ‌ها فقط در همان مرورگرِ خودِ کاربر(در localStorage) نگه داشته می‌شوند تا با رفرش صفحه پاک نشوند.

از اینجا میتونی بهش دسترسی داشته باشی:
https://qfennel.github.io/kink-jars/
